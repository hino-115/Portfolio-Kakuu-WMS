# 論理エンティティ属性定義

## 1. 概要

正規化後の論理エンティティについて、業務上必要な属性と共通管理項目を整理する。

## 2. 成果物

- [論理エンティティ属性定義](./論理エンティティ属性定義.md)（25エンティティ・270属性）
- 関連資料：[論理エンティティキー設計](../04_キー設計/論理エンティティキー設計.md)

## 3. 全体整合性確認・後続工程への引継ぎ

| 対象 | 決定事項・引継ぎ事項 |
| --- | --- |
| キー設計 #63 | 商品ID・SKUID・会社IDを追加し、参照属性名称、PK・FK、一意性、必須・任意、履歴参照の扱いを確定。物理的な制約・採番の実装方法は後続工程で定義する。詳細はキー設計資料を参照 |
| 期限管理 | カテゴリで要否、商品で日数を保持。基準日・具体的な長期日数・数量0時の期限必須条件は要確認 |
| 在庫・入庫 | 棚・段のビュー取得、在庫0の場合の仮引当物理削除・在庫物理削除・オリコン割当解除（同一トランザクション）、在庫減算・引当解消の一体処理、同時実行制御 |
| 出荷 | 検品済・出荷未確定数量を含む集計、出荷日一括更新の要否、再発行時のデータ処理 |
| CSV | 会社・種別の重複制御、JSON構造・容量超過時の記録方法、保持期間。過去の取込種別は結果単体から一意に特定できない場合がある |
| 共通 | 状態値、保持期間、未確定の必須・任意と値の範囲、初期社員登録時の管理項目 |
| 論理ER #64 | 関連・多重度・任意性、削除を許容する履歴参照の表現 |
