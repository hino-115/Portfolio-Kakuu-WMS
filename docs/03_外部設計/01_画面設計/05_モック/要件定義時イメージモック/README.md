## モックのファイル

[画面モックのHTMLファイル（index.html）](./index.html)

**注意：GitHub上のリンクをクリックしても、モックは操作できません。** GitHubではHTMLのコードが表示されます。操作して確認するには、以下の手順でパソコンに保存します。

## モックの起動方法

1. GitHubのリポジトリ画面を開く（PRのマージ前はIssue #38の作業ブランチを選ぶ）。
2. 緑色の **「Code」** ボタンをクリックし、**「Download ZIP」** を選ぶ。
3. ダウンロードしたZIPファイルを展開（解凍）する。
4. 展開したフォルダの中で、次の場所を開く。
   `docs/03_外部設計/01_画面設計/05_モック/要件定義時イメージモック/`
5. `index.html` を**ダブルクリック**する。ChromeやEdgeなどが起動して、モック画面が表示される。
6. 画面のログインボタンを押す（認証処理はモック）。

※ `index.html`、`app.js`、`styles.css` は同じフォルダに置いたまま使用する。

## 注意事項
- あくまで要件定義時に決まっているボタンの仮配列である。
- 詳細な検索項目やボタン配置などについては基本設計時に決まる
- 要件定義で未確定とされている列、配置、ページング、検索一致方式、ボタン活性条件等は仮表示。
- バックエンド・DB接続なし。
- SCR-001〜SCR-027のうち、画面一覧に定義された画面をSPA形式で確認可能。
