## 3. ユースケース一覧の変更履歴・採番方針

### 3.1 UC-003・UC-004の統合

- **UC-003「仕入情報を確認する」**は、**UC-005「入荷予定情報を確認する」**へ統合した。
- **UC-004「仕入情報を取り消す」**は、**UC-007「入荷予定情報を削除・取消する」**へ統合した。
- UC-003とUC-004は有効ユースケースから除外するが、採番履歴を残すため、ユースケース一覧に旧名称を保持する。

### 3.2 UC-050の追加

- **UC-050「在庫を移動する」**を新たにユースケース一覧へ追加した。
- 在庫管理担当者が対象オリコンを選択し、移動先のロケーション・棚・段を指定して、オリコン単位で保管場所を変更するユースケースである。
- UC-050の追加はUC-003・UC-004の統合とは別の変更として扱う。

### 3.3 UC-051の追加と既存ユースケースの修正

- **UC-051「読み取り設定マスタを管理する」**をシステム運用管理者のユースケースとして追加した。
- UC-042は会社に対する読み取り設定の割当管理とし、読み取り設定自体の管理をUC-051に分離した。
- UC-033・UC-034は出荷情報の修正条件と出荷確定単位を見直し、UC-044はログインIDの表記に統一した。

一覧の採番範囲はUC-001～UC-051、有効ユースケースは49件とする。

## 4. ユースケース図の更新方針

**今回、draw.ioファイルおよび閲覧用PNG画像は更新しない。**

そのため、図には統合前のUC-003・UC-004が残っており、一覧に追加したUC-050は反映されていない。また、注文受付担当者に関するユースケースは一覧に記載されているが、独立した図は作成していない。

現時点では**ユースケース一覧を更新後の内容、ユースケース図を更新前の内容**として区別する。一覧と図の一致が必要になった段階で、図の改訂を検討する。

Issue #67でも上記の更新方針を維持する。UC-051の追加はユースケース図に反映していない。提出用Excelも今回の一覧更新の対象外とし、後日整合性を確認する。
