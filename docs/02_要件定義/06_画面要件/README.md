## 要件定義時の画面モック

画面一覧など、要件定義時点で整理した情報をもとに、画面構成・遷移を確認するための**暫定モック**を作成した。

- [画面モック（index.html）](../../03_外部設計/01_画面設計/05_モック/要件定義時イメージモック/index.html)
- [モックのREADME（起動方法・暫定事項）](../../03_外部設計/01_画面設計/05_モック/要件定義時イメージモック/README.md)

このモックは、**正式な外部設計で確定した画面仕様ではない**。画面レイアウトや未確定の表示・操作条件などは後続の設計で詳細化する。

GitHub上でHTMLファイルのリンクをクリックしても、モックの操作画面は表示されない。**操作して確認するには**、リポジトリの「Code」→「Download ZIP」でファイルをダウンロード・展開し、モックのフォルダ内にある `index.html` をダブルクリックする。詳細は[モックのREADME](../../03_外部設計/01_画面設計/05_モック/要件定義時イメージモック/README.md)を参照する。
