# コンテキスト図

## 1. 概要

本資料は、KAKUU WMSのシステム境界と、外部の関係者・システムとの情報のやり取りを整理したコンテキスト図である。

## 2. コンテキスト図

![コンテキスト図](images/コンテキスト図.png)

## 3. 図中の記載に関する補足・検討事項

- **注文CSV**：図中では「注文CSV」と表記しているが、注文情報の受領方法をCSV形式に限定するものではない。
- **推奨保管場所**：実装するかどうかは、非機能要件または要件定義にて検討中である。
- **在庫調整情報**：実装するかどうかは、要件定義にて検討中である。
