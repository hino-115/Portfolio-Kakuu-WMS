# 概念ER図

## 1. 概念ER図の位置付け

概念ER図は、業務モデルを表すものであり、実装モデルを表すものではない。

## 2. 対象とする情報

概念ER図では、業務上独立して管理する情報を対象とする。

CSV取込・検証処理でのみ使用する仮入荷予定データ、仮出荷データなどの一時データやテンポラリーテーブルは対象外とする。

一時データについては、論理・物理データ設計時にステージングテーブルとして定義する。

## 3. 概念ER図の対象外になりやすい情報

- 一時テーブル・テンポラリーテーブル
- ログ管理などの非機能要件に関する情報
- 状態管理に関する詳細な情報

ただし、上記は必ず対象外になるという意味ではない。業務モデルを表すうえで必要な場合は、概念ER図に含める。

例えば、出荷状態の管理など業務上必要な概念は表現する一方、細かな状態管理まではこの段階で扱わない。
