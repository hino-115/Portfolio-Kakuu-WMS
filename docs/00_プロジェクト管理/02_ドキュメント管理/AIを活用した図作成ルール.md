# AIを活用した図作成ルール

## 1. 目的

本資料は、KAKUU WMSで使用するER図、DFD、業務フロー図などについて、AIを活用しながら見やすく統一された図を作成・管理するための共通ルールを定義する。

## 2. 図の配置・接続ルール

### 2.1 図形の配置

- 図形同士を重ねない。
- 図形内の文字が確認できるように配置する。

### 2.2 接続線の配置

- 接続線は、図形や文字に重ならないように配置する。
- 一つの図形に複数の線を接続する場合は、可能な限り接続位置を分散させる。
- 接続線同士の重なりや交差は、可能な限り避ける。

### 2.3 例外

図の構造上、線の交差や重なりを完全に避けられない場合は、図全体の見やすさを優先して配置を調整する。

## 3. AIを活用した図の作成手順

AIを活用して図を作成する場合は、原則として以下の手順で進める。

ただし、図の種類や作業内容に応じて例外を認める。

### 3.1 図の内容を文章で説明する

ユーザーとAIで、作成する図の目的、登場する要素、要素間の関係などを文章で整理する。

図を作成する前に、必要な情報や関係性を明確にする。

### 3.2 図形のみを配置した図を作成する

AIは、整理した内容を基に図形のみを配置した図を作成する。

この段階では接続線を記載しない。

### 3.3 図形の配置を調整する

ユーザーはAIが作成した図を確認し、必要に応じて図形の位置を変更する。

配置を調整した図は、AIが読み取れる形式で保存し、共有する。

### 3.4 接続線と必要な情報を追加する

AIは、ユーザーが配置を調整した図を読み取り、事前に整理した要素間の関係に基づいて接続線を追加する。

ER図など、関係の多重度を表す必要がある図では、多重度も記載する。

接続線の追加時には、第2章の配置・接続ルールを適用する。

## 4. 図の保存・管理

### 4.1 編集元ファイル

図の編集元ファイルは、原則としてdraw.io形式で保存する。

編集元ファイルは、ドキュメント管理に関する共通ルールに従い、`source/` に格納する。

### 4.2 閲覧用画像

Markdownから図を確認できるように、PNGなどの閲覧用画像を作成する。

閲覧用画像は `images/` に格納し、Markdown内から相対パスで参照する。

### 4.3 ファイル名

図の編集元ファイルおよび閲覧用画像の名称は、別途定義した「命名規則」に従う。

### 4.4 図の変更

図を変更した場合は、必要に応じて閲覧用画像も更新し、編集元ファイルとの整合性を維持する。

設計過程を示すために必要な中間成果物は、最終成果物と区別して保存してよい。
