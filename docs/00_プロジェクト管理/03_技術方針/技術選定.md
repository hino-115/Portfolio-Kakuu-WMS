# KAKUU WMS 技術選定

## 1. 使用言語・マークアップ等

- Java
- SQL
- HTML
- CSS
- JavaScript
- JSP

## 2. バックエンド

- Spring Boot 4.2.0
- JDK 21
- Spring MVC
- Spring JDBC
- Bean Validation

### 基本構成

以下のレイヤ構成を基本とする。

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
MySQL
```

画面表示にはJSPを使用する。

```text
Controller
    ↓
JSP
```

各層の詳細な責務や実装ルールについては、内部設計およびコーディング規約で定める。

## 3. フロントエンド

- JSP
- HTML
- CSS
- JavaScript

CSSは独自CSSを使用する。

JavaScriptは標準JavaScriptを使用する。

以下は使用しない。

- Bootstrap
- jQuery

## 4. データベース

- MySQL 8.4 LTS
- MySQL Connector/J
- Spring JDBC

### データベース基本設定

- 文字コード：utf8mb4
- 照合順序：utf8mb4_0900_ai_ci
- タイムゾーン：Asia/Tokyo

### SQLファイル管理

DDLはSQLファイルとしてGitで管理する。

初期データについてもSQLファイルとしてGitで管理する。

## 7. 開発補助

- Lombok
- Bean Validation

## 8. ログ

- Logback

ログレベル、出力先、ローテーション等の詳細については、コーディング規約または実装時の設計で定める。

## 9. 設定ファイル

設定ファイルには以下を使用する。

- `application.properties`

環境依存情報は環境変数を利用する。

DB接続情報などの機密情報はGitHubへ直接コミットしない。

例：

```properties
spring.datasource.url=${DB_URL}
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}
```

## 10. 文字コード・改行コード

### テキストファイル

- 文字コード：UTF-8
- 改行コード：LF

対象例：

- `.java`
- `.sql`
- `.html`
- `.css`
- `.js`
- `.jsp`
- `.md`
- `.properties`

### Officeファイル

以下のファイルはUTF-8・LF統一の対象外とする。

- `.docx`
- `.xlsx`
- `.pptx`

Officeファイルは各アプリケーションの標準形式で保存する。

## 11. 日時の基本方針

- システムの基準タイムゾーンは Asia/Tokyo とする。

## 12. 開発環境

- OS：Windows
- IDE：Eclipse
- DB管理：MySQL Workbench

ローカル環境ではSpring BootアプリケーションをWindows上で実行し、MySQLもローカル環境で使用する。
